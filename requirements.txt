# Python dependencies for this repository.
#
#   python -m venv .venv
#   .venv\Scripts\activate          # Windows
#   source .venv/bin/activate       # macOS / Linux
#   pip install -r requirements.txt
#
# What needs what:
#
#   manim    the video. It additionally needs ffmpeg and a LaTeX distribution
#            on PATH, neither of which pip can install;
#            `python scripts/create_video.py --check` reports what it finds.
#   openai   `python scripts/run_lats.py --llm openai`, which reads
#            OPENAI_API_KEY from the environment.
#
# The default `--llm mock` policy imports neither, so a search still runs on
# the standard library alone, offline and with no API key. The trace viewer is
# a Node project and needs none of this - see README.md.
